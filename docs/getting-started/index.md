# Getting started

Install neon-mcp, connect an MCP client, add your NEON API token and tune the configuration.

* [Install neon-mcp](install.md) - Install the neon-mcp server with uv or pip from GitHub (or PyPI once released), verify it with --version and --check, and run it from source.
* [Quickstart](quickstart.md) - A first session with neon-mcp: register it with Claude Code, check it with neon_ping, then find a product, check availability, list files and cite.
* [NEON API token](api-token.md) - Why NEON's data and sample endpoints require an API token, how to obtain one, how neon-mcp reads it, and the rate limits that apply with and without it.
* [Clients](clients.md) - Register neon-mcp with Claude Code, Claude Desktop, Codex CLI, OpenCode and Antigravity over stdio, or connect to a hosted server over HTTP.
* [Configuration](configuration.md) - Configure neon-mcp with a YAML file, NEON_MCP_ environment variables or command-line flags; precedence rules and every setting with its default.
