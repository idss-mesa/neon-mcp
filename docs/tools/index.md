# Tools

neon-mcp exposes 20 tools (19 over HTTP, where downloads are not offered). Start
with the generated [Tool reference](reference.md) for exact inputs and result
fields; the family pages explain when to use which tool and what to watch for.

* [Tool reference](reference.md) - Every tool with its inputs, result fields, NEON endpoints, token requirement and annotations, generated from the registry.
* [Products](products.md) - Find data products by keywords, theme or team, read a product in depth, and navigate its opt-in detail sections.
* [Sites](sites.md) - Find NEON field sites by name, state, domain, product or proximity, and read one site with its products.
* [Locations](locations.md) - Walk site, domain and REALM hierarchies by location type (towers, plots, huts) and read one location in depth.
* [Availability and data files](availability-and-data.md) - Check which sites and months have data, list data files with signed URLs, and download them safely on stdio.
* [Releases and citations](releases.md) - Browse NEON's annual releases and DOIs, read one release, and produce correct citations.
* [Taxonomy](taxonomy.md) - Page through NEON taxon lists by type code or rank, with exact-name matching and a genus fallback.
* [Samples](samples.md) - Look up sample classes and a physical sample's custody chain, including the one multi-round-trip tool.
* [Prototype datasets](prototype-datasets.md) - Search NEON's prototype datasets and read one with its files, DOI and descriptions.
* [GraphQL](graphql.md) - The guard-railed read-only GraphQL tool for shapes the dedicated tools do not cover.
* [Utilities and errors](utilities.md) - Status checks, NEON documents (ATBDs, protocols) and the error codes every tool can return.
* [Resources and prompts](resources-and-prompts.md) - The neon:// guides and references, the three resource templates, and the three prompts.
